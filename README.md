# Cocoon Bloom Studio

Build a stunning, premium web application called "Silk Cocoon AI".

This is an AI-powered silk cocoon segmentation and analysis platform.

I DO NOT want a generic AI dashboard.

I want the entire experience to feel alive, inspired by nature, silk farms, caterpillars, butterflies, cocoons and leaves.
